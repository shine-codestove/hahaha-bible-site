# 하하하 바이블 탐험 – 웹사이트

어린이 성경 게임 「하하하 바이블 탐험」의 소개, 지원, 개인정보 처리방침, 이용약관 페이지입니다. GitHub Pages 로 배포하는 정적 사이트입니다.

- `index.html` 소개 · `support.html` 지원/FAQ (App Store 지원 URL) · `privacy.html` 개인정보 처리방침 · `terms.html` 이용약관
- 영어판: `en/` 폴더에 같은 네 쪽 (그림·스타일·스크립트는 위 폴더의 것을 같이 쓴다, `<html data-base="../">`). 머리의 🌐 버튼으로 오가고 고른 언어를 기억한다. 브라우저 언어가 페이지 언어와 다르면 작은 안내만 띄운다 (자동으로 옮기지 않음)
- 새 언어는 `<언어>/` 폴더를 더하고, 모든 쪽의 `hreflang` 링크와 언어 버튼에 그 언어를 더한다
- 앱 저장소: shine-codestove/hahaha-bible-adventure (비공개)
